winr0x2migrated from CVSWindows tweakerformerly WinRUS for Windows 98--               Программа - редактор реестра в симпатичной оболочке, позволяет изменять многие настройки, недоступные средствами операционной системы.                                 7.03.2001                   rasa--        В "комплект" программы winr0x Second Edition 2001 for Windows 98  входят 5 файлов:     winr0x2.exe   - программа   winrus.hlp   - файл справки   winrus.cnt   - указатель файла справки   lsansuni.ttf	- файл шрифта True Type   readme.txt   - этот файл  Если winr0x2 не будет понятно отображать кириллицу, то проинсталируйте шрифт Lucida Sans Unicode. Для этого откройте папку C:\Windows\Fonts выберите в меню Файл опцию Установить шрифт... В появившемся окне укажите файл lsansuni.ttf и нажмите кнопку OK.                                                            rasa																														![winr0x2.gif](https://github.com/roosslan/winr0x2/blob/trunk/winr0x2.gif?raw=true)
